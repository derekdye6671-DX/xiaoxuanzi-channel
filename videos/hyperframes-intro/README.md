# 小玄子｜十秒中文片头

片头文字：**从一个想法 → 用 AI 做点真东西 → 小玄子**。

![成品关键画面](预览.jpg)

规格：横屏 1920×1080、30 帧/秒、10 秒、H.264 MP4。按用户选择无声，适合导入剪映后配自己的音乐。

## 直接使用成品

本机成品位于本文件夹的 `renders/小玄子-10秒中文片头.mp4`。把它拖入剪映素材区，再拖到时间线最前面。视频和缓存已忽略，不提交到 GitHub。

验证成功：播放共 10 秒，先看到「从一个想法」，接着出现「用 AI / 做点真东西」，最后定格在「小玄子」。没有音轨属于预期行为。

## 重新打开和修改

双击本文件夹的 **打开预览.cmd**，在本地编辑界面播放视频、修改文字和时间轴。预览地址为 http://localhost:3017/#project/hyperframes-intro 。需要进一步修改时，在 Codex 里描述要改的文字、颜色或节奏即可。

修改后双击 **导出片头.cmd**：先自动检查画面，再导出带时间戳的新 MP4，避免覆盖已有成品。第一次下载 CLI 或浏览器依赖时可能需要联网。

字体包含当前片头所需字形；新增文字如果显示方框，应让 Codex 补齐字体子集。不要用真实工作资料或个人敏感信息试验。

## 本机运行依赖

- Node.js 24.22.3 与 npm 11.19.1：安装在 D 盘工具目录。
- HyperFrames CLI：固定 0.9.102，通过官方技能启动器调用。
- FFmpeg、FFprobe：9.1；浏览器：本机 Chrome。
- 无须为这个纯文字片头安装 Docker、转录模型、配音模型或本地音乐模型。
- 使用官方开关关闭遥测。没有上传视频、申请付费服务或公开发布预览。
